# Handpost

This repository holds the files served at https://handpost.page.

Handpost is a messaging app that works like letters. Open https://handpost.page in a browser to use it (nothing to install). Letters are sealed on your device before they leave, so nobody in between can read them. When you are not directly connected to the other person's device, your letter goes into their mailbox, and they receive it the next time they open Handpost. The mailbox is a small server (an Evernode instance) that each person rents for themselves.

- The files here are exactly what handpost.page serves (GitHub Pages).
